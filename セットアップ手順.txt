# プロジェクト管理ボード セットアップ手順

## 📱 PCとiPhoneで同期するカンバンボード

---

## ステップ1: Firebaseプロジェクト作成（5分）

### 1-1. Firebase Consoleにアクセス
https://console.firebase.google.com/

### 1-2. 新しいプロジェクトを作成
1. 「プロジェクトを追加」をクリック
2. プロジェクト名: `promotion-board`（任意）
3. Google アナリティクスは不要 → 無効にしてOK
4. 「プロジェクトを作成」をクリック

### 1-3. Realtime Database を作成
1. 左メニュー「構築」→「Realtime Database」
2. 「データベースを作成」をクリック
3. ロケーション: `asia-southeast1`（シンガポール）を推奨
4. セキュリティルール: **「テストモードで開始」**を選択
5. 「有効にする」をクリック

⚠️ **重要**: テストモードは60日間のみ有効です。本番運用する場合は後でルールを変更してください。

### 1-4. ウェブアプリの設定を取得
1. プロジェクト概要（歯車アイコン）→「プロジェクトの設定」
2. 「マイアプリ」セクションで「ウェブ」アイコン（</>）をクリック
3. アプリのニックネーム: `promotion-board-app`（任意）
4. 「アプリを登録」をクリック

### 1-5. 設定情報をコピー
表示される `firebaseConfig` をコピーします:

```javascript
const firebaseConfig = {
  apiKey: "AIza...",
  authDomain: "promotion-board-xxxxx.firebaseapp.com",
  databaseURL: "https://promotion-board-xxxxx.firebaseio.com",
  projectId: "promotion-board-xxxxx",
  storageBucket: "promotion-board-xxxxx.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:xxxxx"
};
```

## ステップ2: HTMLファイルを編集（2分）

### 2-1. index.htmlをテキストエディタで開く

### 2-2. Firebase設定を貼り付け
ファイル内の以下の部分を探します（下の方にあります）:

```javascript
const firebaseConfig = {
    // Firebase Console から取得した設定をここに貼り付け
};
```

↓ これを、ステップ1-5でコピーした設定に置き換えます:

```javascript
const firebaseConfig = {
  apiKey: "AIza...",
  authDomain: "promotion-board-xxxxx.firebaseapp.com",
  databaseURL: "https://promotion-board-xxxxx.firebaseio.com",
  projectId: "promotion-board-xxxxx",
  storageBucket: "promotion-board-xxxxx.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:xxxxx"
};
```

### 2-3. ファイルを保存

---

## ステップ3: GitHub Pagesで公開（3分）

### 3-1. GitHubリポジトリにファイルをアップロード

**方法A: GitHub Web UI使用**
1. GitHubリポジトリを開く
2. 「Add file」→「Upload files」
3. `index.html` をドラッグ&ドロップ
4. 「Commit changes」をクリック

**方法B: Git コマンド使用**
```bash
git add index.html
git commit -m "Add project management board"
git push origin main
```

### 3-2. GitHub Pagesを有効化
1. リポジトリの「Settings」タブを開く
2. 左メニュー「Pages」をクリック
3. Source: `main` ブランチを選択
4. フォルダ: `/ (root)` を選択
5. 「Save」をクリック

### 3-3. 公開URLを確認
数分後、以下のような形式でURLが表示されます:
```
https://あなたのユーザー名.github.io/リポジトリ名/
```

## ステップ4: PCとiPhoneでアクセス（1分）

### PC
1. ブラウザで公開URLを開く
2. ブックマークに追加

### iPhone
1. Safariで公開URLを開く
2. 画面下部の「共有」ボタンをタップ
3. 「ホーム画面に追加」をタップ
4. アイコンがホーム画面に追加される

✅ **完了！** PCとiPhoneでデータが自動同期されます

---

## 使い方

### プロジェクトの追加
1. 上部の入力欄にプロジェクト名を入力
2. 「➕ 追加」ボタンをクリック

### ステータスの変更
**PC**: カードをドラッグ&ドロップで別の列に移動
**iPhone**: カードを長押しして別の列までドラッグ

### プロジェクトの削除
カード内の「削除」ボタンをクリック

### データ同期
- PCで変更 → iPhoneに即座に反映
- iPhoneで変更 → PCに即座に反映
- ステータス表示: 画面上部に「🟢 同期中」と表示

---

## トラブルシューティング

### 「ローカルモード」と表示される
→ Firebase設定が正しく貼り付けられていません。ステップ2を再確認してください。

### データが同期されない
1. Firebaseコンソールでデータベースが作成されているか確認
2. ブラウザのコンソール（F12）でエラーを確認
3. 両方のデバイスでインターネット接続を確認

### iPhoneでドラッグできない
→ カードを長押ししてから移動してください

### GitHub Pagesが表示されない
→ 公開まで最大10分かかる場合があります。少し待ってから再度アクセスしてください。

## セキュリティについて

⚠️ **注意事項**:

1. **URLを知っている人は誰でもアクセス可能**
   - 機密情報は入れない
   - URLを他人に教えない

2. **Firebaseのテストモードは60日間のみ**
   - 60日後はセキュリティルールの更新が必要
   - Firebase Consoleで通知が来ます

3. **より安全にする方法**（必要に応じて実施）
   - Firebase Authentication（認証）を追加
   - セキュリティルールを厳格化
   - パスワード保護を追加
